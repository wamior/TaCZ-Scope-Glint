# TaCZ Scope Glint 1.1.0

- Optical scope classification uses TaCZ metadata, including third-party gunpacks.
- Hybrid sights check the selected optical lens, independently of ADS zoom.
- Solid cover blocks glints along the entire sight line; the effect is never moved outside a wall.
- Removed forced extension of player render distance.
- Added Minecraft 1.18.2, 1.19.2 and 1.20.1 Forge builds and an official TaCZ 1.2.0 NeoForge 1.21.1 build.
- Added optional clickable update notices using Forge/NeoForge's built-in checker.

Install on the client alongside the matching TaCZ version. The server does not need this addon.
